## কিভাবে চালাবেন
1. পুরো `black-force-007-quiz/` ফোল্ডারটি ডাউনলোড করুন।
2. ব্রাউজারে `index.html` খুলুন।
3. গেম স্বয়ংক্রিয়ভাবে শুরু হবে।
4. প্রশ্নের উত্তর দিন, স্কোর ও টাইমার দেখুন।
5. শেষ হলে ফলাফল ও লিডারবোর্ড দেখানো হবে।

## ডিপ্লয়মেন্ট
- এই গেম **Vercel** বা যেকোনো **Static Hosting**-এ সহজেই আপলোড করা যাবে।
- সম্পূর্ণ ক্লায়েন্ট-সাইড হওয়ায় **কোনো ব্যাকএন্ড প্রয়োজন নেই**।

## কাস্টমাইজেশন
- `questions.js` ফাইলে প্রশ্ন, উত্তর এবং বিকল্পগুলো পরিবর্তন করতে পারেন।
- `styles.css` ফাইলে রং ও থিম কাস্টমাইজ করতে পারবেন।
